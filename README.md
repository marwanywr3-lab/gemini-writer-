# سَرد | ملاذ كتاب القصص والمحتوى المقروء 🖋️☕

> **تطبيق ويب دافئ، بسيط، وهادئ مُصمم خصيصاً لكتاب الروايات، القصص القصيرة، والمحتوى السردي المقروء، لمساعدتهم على تنظيم خيوط الحكاية، بناء الشخصيات، وصياغة النصوص في بيئة مريحة خالية من أي مشتتات.**

---

## ✨ المميزات الرئيسية للمشروع

### 1. واجهة دافئة ومريحة للنفس (Warm & Serene UI)
- **ألوان هادئة وطبيعية**: مستوحاة من دفء الورق القديم، الحبر العتيق، ودرجات القهوة والتراكوتا (Warm Parchment, Sepia, Night Mode, Minimal).
- **طباعة عربية مريحة للعين**: خطوط عربية أدبية أصيلة مختارة بعناية (`Alexandria`, `Amiri`, `Tajawal`, ونظام التشغيل الافتراضي) مع إمكانية تكبير وتصغير حجم الخط بما يناسب بصر الكاتب.
- **عرض نصي متوازن**: محاذاة وقياس سطور مدروس بدقة (Max-Width 760px) لمنع إجهاد العين أثناء جلسات الكتابة الطويلة.

### 2. بيئة كتابة نقية خالية من المشتتات (Zen Focus Mode)
- **وضع السكون (Zen Mode)**: إخفاء كافة القوائم والأزرار بضغطة زر أو باختصار لوحة المفاتيح، لتبقى أنت وورقتك وأفكارك فقط.
- **وضع الآلة الكاتبة (Typewriter Scrolling)**: يضمن إبقاء السطر النشط دائماً في منتصف الشاشة رأسياً أثناء الكتابة المستمرة.
- **حفظ تلقائي فوري**: تخزين محلي آمن في المتصفح (`LocalStorage`) بدون الحاجة لقلق الكاتب بشأن فقدان أي فكرة.

### 3. مدير الفصول والمشاهد (Chapters & Scenes)
- تقسيم العمل الروائي أو المقروء إلى فصول ومشاهد منظمة.
- إعادة ترتيب الفصول بسهولة (تقديم وتأخير).
- تتبع حالة كل فصل: (مسودة 🟡، مراجعة 🟢، مكتمل 🔵).
- عداد كلمات خاص بكل فصل على حدة.

### 4. سجل الشخصيات (Character Codex)
- بطاقات مخصصة لكل شخصية تشمل:
  - الاسم والدور (بطل، غريم، مساند، ثانوية).
  - العمر والمهنة.
  - الدافع والرغبة الكبرى في القصة (Goal & Motivation).
  - نقطة الضعف أو الصراع الداخلي (Inner Flaw & Conflict).
  - المظهر الخارجي والسمات الفريدة.

### 5. دليل العوالم والملاحظات (World Building & Lore)
- توثيق تفاصيل الأماكن، الجغرافيا، أسرار الحبكة، والخطوط الزمنية للقصة في بطاقات سريعة الوصول.

### 6. أصوات هادئة مدمجة (Web Audio Ambient Engine)
- توليد أصوات تركيز طبيعية برمجياً بنسبة 100% عبر تقنية `Web Audio API` دون الحاجة لأي ملفات صوتية خارجية ثقيلة:
  - 🌧️ **المطر الهادئ** (قطرات خفيفة على الزجاج).
  - 🪵 **دفء الموقد وطقطقة الحطب** (أجواء شتوية دافئة).
  - 🍃 **همس الرياح الليلية** (نسيم هادئ محفز للخيال).
  - تحكم مستقل بمستوى صوت كل تأثير صوتي بالإضافة إلى مستوى الصوت العام.

### 7. مُلهم السرد وعلاج قفلة الكاتب (Story Sparks)
- بنك أفكار غني باللغة العربية يقدم:
  - منعطفات حبكة مفاجئة (Plot Twists).
  - صراعات ومواجهات درامية.
  - تفاصيل حسية ومؤثرات لوصف المشهد.
  - بدايات جمل ملهمة يمكن إدراجها بضغطة زر في النص الحالي.

### 8. إحصائيات وأهداف الجلسة (Writing Stats & Goals)
- عداد الكلمات الإجمالي والحروف.
- حساب زمن القراءة التقديري للنص المكتوب.
- شريط تقدم لهدف الكلمات اليومي (Daily Word Count Goal).
- ومضات ونصائح أدبية متجددة للكتاب.

### 9. تصدير شامل بعدة صيغ
- **معاينة وطباعة الكتاب (Manuscript Print)**: إخراج الرواية بتنسيق كتاب ورقي أنيق جاهز للحفظ بصيغة PDF أو الطباعة المباشرة.
- **ملف نصي نقي (.txt)**: لتجميع كامل الفصول في ملف واحد قابل للفتح على أي جهاز.
- **ملف ماركداون (.md)**: منسق بالعناوين والاقتباسات.
- **نسخة احتياطية كاملة (.json)**: لحفظ العمل كاملاً بجميع فصوله وشخصياته وملاحظاته واسترجاعه في أي وقت.

## 🚀 طريقة تشغيل المشروع

المشروع مصمم ليكون **مستقلاً بنسبة 100% وخالياً من أي تبعات معقدة**:

### الطريقة الأبسط (تشغيل مباشر دون أي تثبيت):
1. قم بفك ضغط ملف `sard-writer-studio.zip`.
2. انقر نقراً مزدوجاً على ملف `index.html` ليفتح في أي متصفح حديث (Chrome, Safari, Edge, Firefox).
3. سيعمل التطبيق فوراً بجميع مميزاته!

### تشغيله عبر خادم محلي (اختياري للمطورين):
إذا كنت تفضل تشغيله عبر سيرفر محلي بواسطة Node.js أو Python:
```bash
# باستخدام بايثون 3
python3 -m http.server 8080

# أو باستخدام npx
npx serve .
```
ثم افتح المتصفح على الرابط: `http://localhost:8080`.

## ⌨️ اختصارات لوحة المفاتيح السريعة

| الاختصار | الوظيفة |
| :--- | :--- |
| `Ctrl + S` / `Cmd + S` | حفظ فوري للتعديلات |
| `Ctrl + B` / `Cmd + B` | طي أو إظهار القائمة الجانبية |
| `Esc` | الخروج من وضع السكون (Zen Mode) أو إغلاق النوافذ |
| `Ctrl + B` (داخل النص) | جعل النص المظلل عريضاً (Bold) |
| `Ctrl + I` (داخل النص) | جعل النص المظلل مائلاً (Italic) |
